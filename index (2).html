🚀 SIAP UNGGAH KE HOSTING GRATIS (NETLIFY / GITHUB PAGES / TIINY.HOST)

Klik tombol di samping untuk mengunduh file bernama index.html (sudah termasuk judul & 20 soal yang Anda atur). Saat di-hosting di internet, koneksi antar-HP siswa (WebRTC P2P) otomatis aktif!

OPSI 1: NETLIFY DROP (TERCEPAT)

1. Klik tombol Unduh index.html di atas.
2. Masukkan file index.html tersebut ke dalam 1 Folder baru di komputer Anda.
3. Buka app.netlify.com/drop lalu seret (drag & drop) folder tersebut. Link game langsung jadi!

OPSI 2: TIINY.HOST / SURGE

1. Buka situs tiiny.host.
2. Unggah file index.html yang sudah Anda unduh.
3. Ketik nama link kelas Anda (misal: mario-kelas5), klik Publish, dan bagikan link ke WhatsApp kelas!

OPSI 3: GITHUB PAGES

1. Buat repository gratis di github.com.
2. Upload file index.html.
3. Masuk ke menu Settings → Pages, pilih branch main lalu Save. Gratis selamanya!
